    softsim¶

    Simulation of soft materials and soft robots, validated against real data, with the same YAML running on several physics engines:

    Backend What it is Use it for
    mujoco MuJoCo flex (linear tetrahedra) speed: control, sweeps, interactive viewing
    sofa SOFA v26.06 through SofaPython3 more material laws, SOFA's contact
    fem softsim's own locking-free 3D finite elements (quadratic tetrahedra) the truth the others are checked against
    rod slender bodies reduced to beams (SOFA BeamAdapter) cables, arms and columns, in seconds

    Every backend declares what it can simulate and refuses what it can't, so a scene never quietly runs different physics. A fast backend's error against the reference is measured (softsim transfer) and stated. The benchmark table lists every validated case on every backend.

    Install¶

    python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"            # MuJoCo, gmsh, scipy, pytest
.venv/bin/pip install -e ".[fem,fast]"       # optional: the reference FEM (JAX) and PARDISO

    Without the repository: pip install "softsim[mujoco,mesh]" and softsim examples copy my_examples copies a few runnable configs (drop test, cable and PneuNet scenarios, Gymnasium envs); replace scenarios/ by my_examples/ in the commands of the tutorials (those scenarios are in the copy).

    On ROS 2 Humble, create the venv with --system-site-packages (ROS 2). For SOFA, unzip the SOFA v26.06 Linux release and set SOFA_ROOT (SOFA backend).

    Five lines¶

    from softsim import Simulation

sim = Simulation("scenarios/actuation/cable_cantilever.yaml", ["body.mesh.size=2.5mm"], backend="mujoco")
result = sim.run()
print(result.summary["final_bend_angle"])   # rad; Euler-Bernoulli says 0.270
